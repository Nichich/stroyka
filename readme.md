# Добрострой 25 - материалы по заданию

Это ветка task. Здесь не код, а вся документация по проекту - от постановки задачи до гитфлоу. Сам сайт лежит в ветке main.

Проект - сайт строительной компании Добрострой 25 из Владивостока. Продаём тротуарную плитку, стеновые блоки и бордюры. Подробнее про сам сайт и как его запустить - в README.md ветки main.

## Что где лежит

- task.md - постановка задачи: аудитория, трафик, что продаём и как добиваемся продаж.
- terms.md - техническое задание (по структуре ГОСТ 34.602-89).
- design/ - дизайн-проект, выгруженный из Figma (PDF, разбит на части по страницам, см. design/README.md).
- app/ - схемы пользовательских путей (userflow):
  - app/userflow.md - общая карта переходов;
  - app/buyer-flow.md - путь частника;
  - app/b2b-flow.md - путь оптовика и дилера;
  - app/admin-flow.md - путь админа.
- review.md - оценка проекта: критерии и сравнение с конкурентами.
- optimize.md - оптимизация: зачем, что и как, замеры до/после.
- remark.md - идеи по дальнейшему развитию.
- grow.md - гитфлоу проекта.
- prstrategy.md - стратегия продвижения: каналы, сезонность, как привлекаем клиентов.
- readme.md - этот файл.

## Ветки

- main - сайт.
- task - эта ветка, документация.

## С чего начать читать

Если смотришь впервые - идти лучше так: task.md (что и зачем) → terms.md (что именно делаем) → design/ (как выглядит) → app/ (как ходит пользователь) → review.md и optimize.md (что получилось и что улучшили) → remark.md (куда дальше). grow.md - про процесс разработки, prstrategy.md - про продвижение.
