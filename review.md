# Оценка проекта

## По каким критериям оцениваю

Взял то, что реально влияет на продажи и удобство для такого сайта:

1. Каталог и фильтры - можно ли быстро найти нужный товар под задачу.
2. Цены - видны сразу или "уточняйте".
3. Оформление заявки - сколько шагов до заявки.
4. Доверие - сертификаты, ГОСТ, отзывы, реальные контакты с картой.
5. Мобильная версия - регион много заходит с телефонов.
6. SEO - есть ли базовая обвязка под поиск.
7. Скорость - как быстро грузится (подробно в optimize.md).
8. Админка - может ли менеджер сам менять каталог и SEO.

## Как наш сайт по этим критериям

| Критерий | Как сделано | Оценка |
|---|---|---|
| Каталог и фильтры | Фильтры по типу, цене, цвету, форме, высоте, назначению + сортировка | хорошо |
| Цены | Видны сразу в карточке, есть скачивание каталога | хорошо |
| Заявка | Через корзину или контакты, в пару кликов | хорошо |
| Доверие | Страница сертификатов (ГОСТ 17608-2017, ТП 244, ТП 204), отзывы по типам клиентов, Яндекс.Карта | хорошо |
| Мобильная версия | Адаптив, отдельные мобильные ассеты, мобильный фильтр-модалка | хорошо |
| SEO | title/description/keywords, Open Graph, robots, sitemap, правка из админки | хорошо |
| Скорость | Next.js, оптимизация картинок - см. optimize.md | средне, есть куда расти |
| Админка | CRUD по товарам, цвета, опции, категории, заказы, SEO | хорошо |

## Что хорошо

- Фильтр построен под реальные параметры товара, а не абстрактный. Назначение (пешеходная зона / легковые / грузовые) - то, что реально спрашивают.
- Цены сразу на сайте. В этой нише многие прячут цены за "оставьте заявку", и это бесит.
- Отзывы разбиты по типу клиента - частник видит частника, опт видит опт.
- Менеджер сам правит каталог и SEO, не дёргая разработчика.

## Что слабее

- Отзывы и часть карточек сейчас на демо-данных (одинаковый текст, картинка-заглушка test.jpg). Перед боевым запуском нужно залить реальные.
- Нет онлайн-оплаты, всё упирается в звонок менеджера. Для частника это лишний шаг.
- Скорость можно подтянуть (картинки, шрифты, бандл) - см. optimize.md.

## Сравнение с конкурентами

Конкретных прямых конкурентов по Владивостоку много, в основном это:

- сайты местных производителей плитки и бордюров;
- страницы в каталогах типа 2ГИС и Авито без нормального каталога;
- крупные федеральные производители с доставкой в регион.

Сравниваю не с одной конкретной фирмой, а с типичным сайтом из этой ниши, как они обычно сделаны:

| Критерий | Наш сайт | Типичный конкурент в нише |
|---|---|---|
| Цены на сайте | есть сразу | часто "уточняйте по телефону" |
| Фильтр по параметрам | да, по 6 параметрам | часто просто список или категории без фильтра |
| Назначение (нагрузка) в фильтре | есть | редко |
| Сертификаты отдельной страницей | да | бывает, но часто закопано |
| Отзывы по типам клиентов | да | обычно общим списком или нет |
| Мобильная версия | адаптив + мобильный фильтр | бывает кривая или её нет |
| Скачать каталог | да | по-разному |
| Админка для контента | да | часто правки только через разработчика |

Вывод: по удобству каталога, открытым ценам и доверию (сертификаты, отзывы по сегментам) наш сайт выглядит сильнее типичного конкурента в нише. Главные точки, где можно проиграть - скорость загрузки и отсутствие онлайн-оплаты, над этим и стоит работать дальше.
